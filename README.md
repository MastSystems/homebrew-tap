# homebrew-tap

Homebrew tap for [`mast`](https://github.com/MastSystems/mast-spec) — pin what your code promises to the symbols that prove it.

## Install

    brew tap MastSystems/tap
    brew install mast

## Updates

`Formula/mast.rb` is auto-bumped by the [`release-please`](https://github.com/MastSystems/mast-spec/blob/main/.github/workflows/release-please.yml) workflow in `mast-spec` on every release. The version here always matches the [latest GitHub Release](https://github.com/MastSystems/mast-spec/releases/latest).
